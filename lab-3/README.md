# Lab 3 — DOM and Event Handling Drills

This lab contains three self-contained JavaScript pages:

- `quantity.html` — plus/minus quantity stepper with a minimum of 1.
- `search.html` — live filtering of 10 hardcoded product names.
- `email.html` — real-time email validation with a regular expression.

Open any page directly in a browser; this lab does not use Fetch API or a server.
