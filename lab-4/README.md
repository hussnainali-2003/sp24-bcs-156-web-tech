# Lab 4 — Your First API Endpoint

This lab uses a minimal Express server with exactly one route:

- `GET /api/products` returns five hardcoded Tesla products as JSON with HTTP 200.

The page in `index.html` uses `fetch()` to call the endpoint and render the
products. The raw JSON link opens the API response directly in the browser.
