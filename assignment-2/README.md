The Tesla website is used only as a visual and vehicle-presentation reference. This project is an original student-built storefront called **Tesla Vehicles**; it does not copy Tesla's source code or claim to be an official Tesla store.

## What is included

- `index.html` — responsive homepage with a hero section and fifteen Tesla vehicle cards using real photographic car images.
- `product.html` — responsive Tesla Model 3 detail page with image, description, quantity selector, and Add to Cart button.
- `styles.css` — small custom stylesheet for colors, spacing, hover effects, and mobile adjustments.
- `images/` — downloaded local vehicle and hero images used by the pages.
- Bootstrap 5.3 — used for the responsive navbar, container, grid, buttons, and spacing utilities.

## How to run

Open `index.html` in a browser. The vehicle and hero images are stored locally in the `images/` folder. An internet connection is only needed for the Bootstrap CDN files.

## Responsive testing checklist

Use browser DevTools and capture screenshots at:

- Phone: approximately 375px wide
- Tablet: approximately 768px wide
- Desktop: approximately 1366px wide

The navbar collapses on smaller screens and the Bootstrap grid changes from four columns to two columns and then one column.
