# Lab 2 — Responsive Navbar and Grid Drill

This lab practices a responsive Bootstrap navbar and product grid.

## Responsive behavior

- Desktop: four product columns.
- Tablet: two product columns.
- Phone: one product column.
- Below 768px, Bootstrap collapses the navigation links into a hamburger menu.

## Files

- `index.html` — navbar, content, and eight product cards.
- `styles.css` — card styling and small-screen refinements.
- `Lab2_HussnainAli_SP24-BCS-156.pdf` — completion evidence.
